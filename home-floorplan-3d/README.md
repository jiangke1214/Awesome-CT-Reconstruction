# My Home Floorplan 3D — clean project

本分支是独立的户型设计项目，不混用此前试验版本。

## 图纸优先级
- 第二张黑白图：唯一布局依据，决定墙体、门洞、窗洞、结构核心、房间关系。
- 第三张尺寸图：唯一尺寸依据，决定外轮廓尺寸链。
- 第一张彩色图的面积标注不采用；房间面积要根据第二张图描绘出的房间多边形重新计算。

## 已确认尺寸链（mm）
- 上侧：800 + 3200 + 3600 + 2000 + 3200 + 2200 + 2800 = 17800
- 下侧：4000 + 7000 + 1900 + 3500 + 1400 = 17800
- 左侧：1200 + 3700 + 2400 + 5500 + 500 = 13300
- 右侧：1200 + 900 + 2400 + 3850 + 4450 + 500 = 13300

## 当前项目状态
- `index.html`：上游 floorplan-3d 编辑器原版，保留 2D/3D 编辑器功能。
- `data/dimensions.json`：已录入并核对尺寸链。
- `data/walls.json`、`data/rooms.json`、`data/openings.json`、`data/furniture.json`：结构化数据文件已建空模板。
- **墙体逐段描绘尚未完成**。目前不把上游演示户型称为用户真实户型，也不提供未经核对的房间面积。

## 建模顺序
1. 按黑白图描绘外围轮廓与全部承重墙/结构核心。
2. 以尺寸链定位墙体，处理凹凸和错位，不能把户型压成矩形。
3. 录入非承重隔墙、门窗洞口及门扇开启方向。
4. 生成房间多边形并计算净面积。
5. 用户验收 2D 结构后再放置家具、柜体和生成 3D。
