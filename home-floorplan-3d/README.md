# Home Floorplan 3D — clean workspace

这是为用户的住宅户型建立的独立工作分支，和之前的试验版本隔离。

## Source of truth
- 房间布局、墙体相对关系：用户提供的第二张黑白户型图。
- 尺寸链：用户提供的第三张尺寸标注图。
- 第一张彩色图的房间面积标签不作为本项目面积数据来源。

## 已录入的尺寸链（mm）
- 上侧横向：1580 + 240 + 2760 + 240 + 1540 + 240 + 3670 = 10270
- 下侧横向：2180 + 240 + 2160 + 240 + 5450 + 240 + 1340 = 11850
- 左侧纵向：3370 + 1580 + 240 + 2770 + 240 + 2360 = 10560
- 右侧纵向：3370 + 240 + 2760 + 240 + 3950 = 10560

注意：上、下横向总长不同，户型不是一个可以整体缩放的矩形。尺寸链已记录，但尚未完成逐段墙体中心线、墙厚、门窗洞口与房间多边形的对应校准。当前 index.html 是上游 floorplan-3d 编辑器原版示例，不能误认为已经载入用户的真实户型。

## Files
- `index.html`: 上游 floorplan-3d 编辑器原版，保留 2D/3D 编辑功能。
- `data/dimensions.json`: 已确认的尺寸链与校验说明。
- 后续应将墙体、门窗、房间、家具分别拆分为独立数据文件，先完成 2D 结构验收，再做家具和 3D。

用浏览器打开此目录的 `index.html`。3D 引擎依赖网络加载 three.js。
