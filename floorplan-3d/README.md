# 最新户型图 2D / 3D 定制版

此版本已根据用户 2026-11-06 最新上传的黑白户型图重新描绘，替换此前不匹配的户型草图。

## 已录入
- 当前户型的外围轮廓与主要凹凸边界
- 衣帽/书房、厨房、次卧、主卧、客厅、餐厅、客房、家政间、卫生间及玄关等区域
- 主要墙体、窗洞、平开门及推拉门的初步位置
- 厨房操作台、灶具、水槽、岛台、圆餐桌、床、衣柜、沙发、茶几、洗衣机、烘干机及卫浴设备
- 项目原有 2D 编辑、家具拖放、尺寸测量、材料切换和 3D 展示功能

## 尺寸精度
本次上传的黑白户型图没有完整的内部尺寸链。横向 17,800 mm 是按此前尺寸图的横向标尺作为比例基准；纵向约 14,700 mm 是按当前图像比例推算。内部墙厚、门窗洞口、柜体和家具坐标均为图像描绘估算值，不能视为毫米级实测或施工图数据。

如需施工级精度，请补充当前这版户型的 CAD、结构图或带尺寸标注的原始图，并现场复核承重墙、门洞、窗洞及管线位置。
