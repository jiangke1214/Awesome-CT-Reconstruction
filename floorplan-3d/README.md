# 198㎡ 户型 2D / 3D 模型

此目录基于 wy51ai/floorplan-3d 项目建立独立户型数据版本。

## 已录入
- 外围尺寸链：横向 17,800 mm，纵向 13,500 mm。
- 横向分段：800 / 3200 / 3600 / 2000 / 3200 / 2200 / 2800 mm。
- 纵向分段：1200 / 3700 / 2400 / 5500 / 700 mm。
- 初步房间分区、外围墙、主要内隔墙、窗洞、门洞。
- 主要家具：床、衣柜、厨房台面、岛台、圆餐桌、沙发、卫浴设备等。
- 保留项目原有 2D 编辑、家具拖放、尺寸测量、材料切换和 3D 场景。

## 尺寸精度说明
外围尺寸按上传图纸上的尺寸链录入。原图分辨率不足以读取所有内部墙厚、门洞净宽、窗洞宽度和柜体精确尺寸，因此内部隔墙、门窗和家具坐标是按图像比例与常见尺寸建立的**初版估算数据**，不是毫米级实测数据。请在施工前用 CAD / 现场复尺校正。

## 打开
通过支持静态 HTML 的浏览器预览服务打开本目录的 index.html。3D 依赖 three.js CDN，需要联网。
