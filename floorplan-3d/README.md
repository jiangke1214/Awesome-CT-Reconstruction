# 户型定制版（第二张黑白布局 + 第三张尺寸链）

本版本按用户确认的图纸优先级重建：
- 房间位置、墙体关系：以第二张黑白平面图为准。
- 建筑尺寸链：以第三张尺寸图为准。
- 第一张彩色图中的房间面积标签不再沿用。

## 外围尺寸链（mm）
- 横向上侧：800 + 3200 + 3600 + 2000 + 3200 + 2200 + 2800 = 17800
- 横向下侧：4000 + 7000 + 1900 + 3500 + 1400 = 17800
- 纵向左侧：1200 + 3700 + 2400 + 5500 + 500 = 13300
- 纵向右侧：1200 + 900 + 2400 + 3850 + 4450 + 500 = 13300

## 精度限制
外围尺寸链来自尺寸图标注。部分房间边界由黑白图与轴线尺寸对齐推定；内墙厚度、承重属性、门窗净洞口和家具位置仍是模型初值，不可直接作为施工图。

## 使用
打开 `index.html`，可使用原项目的 2D 编辑、家具拖放、尺寸测量、材料切换和 3D 场景。3D 依赖 three.js CDN，需要联网。
